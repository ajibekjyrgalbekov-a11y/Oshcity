# AI-ассистент WhatsApp — как включить

Код готов и проверен тестами (`whatsapp/worker`). Чтобы он заработал, нужно подключить аккаунты. Всё, что связано с паролями, ключами и QR-кодом, делаете **вы сами**. Ключи никому не присылайте, даже в чат с Claude.

## Как это работает
Клиент пишет в WhatsApp → Meta пересылает сообщение на сервер Cloudflare → ассистент (Claude) подбирает квартиры и отвечает → ответ видно у вас в приложении WhatsApp Business на телефоне.
- Когда вы сами пишете клиенту из приложения, ассистент в этом чате молчит 12 часов.
- Голосовое, фото или видео → клиент получает «Ажибек сам посмотрит», а вам приходит сообщение в Telegram. Бот в этом чате встаёт на паузу.
- Встреча, бронь, онлайн-оформление → вам в Telegram приходит карточка клиента со словами «Добавьте в список ‹встреча2›». Список в приложении ставите одним касанием: через API Meta это сделать нельзя.
- Все клиенты пишутся в Google-таблицу, лист «WhatsApp»: одна строка на клиента, со списком и анкетой.
- Правила и факты ассистента лежат в `whatsapp/worker/prompt.md`, цены и условия — в `site/js/config.js`. Свободные квартиры он берёт с сайта, там они обновляются каждое утро.

## Шаг 1. Google-таблица (5 мин)
1. Откройте таблицу → Расширения → Apps Script → замените код на новый `google/Code.gs` → Сохранить.
2. Запустите функцию `setup()`: появится лист «WhatsApp».
3. Развернуть → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть. Ссылка останется прежней (та же, что `sheetUrl` в `site/js/config.js`).

## Шаг 2. Telegram-бот для уведомлений (5 мин)
1. В Telegram откройте @BotFather → `/newbot` → имя, например «OshCity Ажибек». Сохраните токен.
2. Напишите своему новому боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789` — это ваш chat id.

## Шаг 3. Ключ Claude API (5 мин)
console.anthropic.com → Settings → Billing: пополните баланс на $10–20 и поставьте месячный лимит, например $30. Затем API Keys → Create Key.

## Шаг 4. Cloudflare (10 мин)
1. Зарегистрируйтесь на dash.cloudflare.com (бесплатный тариф).
2. В терминале в папке `whatsapp/worker`:
   ```
   npm install
   npx wrangler login
   ```
3. В `wrangler.toml` впишите `TG_CHAT_ID` (из шага 2). `WA_PHONE_NUMBER_ID` впишете на шаге 5.
4. Секреты: каждая команда спросит значение, вставляете его сами:
   ```
   npx wrangler secret put ANTHROPIC_API_KEY
   npx wrangler secret put TG_TOKEN
   npx wrangler secret put TG_SECRET          # придумайте любую длинную строку
   npx wrangler secret put SHEET_URL          # ссылка Apps Script из site/js/config.js
   npx wrangler secret put WA_VERIFY_TOKEN    # придумайте любую строку, она понадобится в Meta
   ```
5. `npm run deploy`: сначала проходят тесты, потом публикация. Запомните адрес вида `https://oshcity-whatsapp.<имя>.workers.dev`.
6. Подключите команды Telegram (подставьте свои значения):
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://oshcity-whatsapp.<имя>.workers.dev/telegram&secret_token=<TG_SECRET>`
   После этого бот понимает `/pause 0555123456` (бот молчит в чате) и `/resume 0555123456` (снова отвечает).

## Шаг 5. Подключение номера к Cloud API (coexistence)
Подключить можно только через провайдера (Tech Provider / BSP) с Embedded Signup. Перед этим шагом сравним 2–3 провайдера по цене и поддержке +996.
1. WhatsApp Business на телефоне обновите до последней версии.
2. В Embedded Signup выберите «подключить существующее приложение WhatsApp Business», войдите в бизнес-портфолио 735665919574388, выберите номер +996 508 890 202 и **отсканируйте QR-код в приложении**. Синхронизацию истории можно разрешить.
3. В бизнес-портфолио Meta добавьте способ оплаты: с 01.10.2026 ответы через API сверх 1000 в месяц платные.
4. Получите у провайдера или в Meta App: **Phone number ID**, **постоянный токен доступа** (System User token с правом `whatsapp_business_messaging`) и **App Secret**:
   ```
   npx wrangler secret put WA_TOKEN
   npx wrangler secret put WA_APP_SECRET
   ```
   `WA_PHONE_NUMBER_ID` впишите в `wrangler.toml` и снова выполните `npm run deploy`.
5. Webhook в Meta App → WhatsApp → Configuration: URL `https://oshcity-whatsapp.<имя>.workers.dev/webhook`, Verify token — тот, что задали в `WA_VERIFY_TOKEN`. Подпишитесь на поля: `messages`, `smb_message_echoes`, `history`, `smb_app_state_sync`, `account_update`.

## Шаг 6. Проверка перед запуском
1. Со второго телефона напишите на +996 508 890 202 на русском и на кыргызском: «сколько стоит 2-комнатная?», «есть 1 млн взнос», «дайте скидку», голосовое, «приду во вторник в 11».
2. Проверьте ответы, карточки в Telegram и строки в таблице.
3. Напишите клиенту сами из приложения: бот должен замолчать в этом чате.
4. Первые дни читайте диалоги бота. Если ответ не нравится, поправьте `prompt.md` и выполните `npm run deploy`.

## Если что-то не так
- Бот не отвечает: `npx wrangler tail` покажет ошибки в реальном времени.
- Срочно выключить бота везде: в Meta отпишите webhook. Приложение на телефоне продолжит работать как обычно.
- Дороже, чем ожидали: в `wrangler.toml` поставьте `MODEL = "claude-sonnet-5-5"` (примерно вдвое дешевле) и выполните `npm run deploy`.
